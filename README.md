# School Management System (SMS)

A comprehensive, modern School Management System designed to streamline academic, administrative, and student operations.

## 🌟 Overview
The School Management System provides an intuitive, high-performance interface for managing:
- **Student Admissions & Profiles** (Personal info, enrollment, class assignment)
- **Academic Management** (Courses, subjects, class schedules, exams)
- **Attendance Tracking** (Daily student & staff attendance with quick reporting)
- **Grading & Report Cards** (Exam marks, GPA/percentage calculation, downloadable report cards)
- **Fee & Financial Management** (Fee structure, invoice generation, payment status)
- **Teacher & Staff Portal** (Staff directory, subject assignment, payroll status)
- **Notice Board & Announcements** (School-wide alerts, event calendar)
